# Social post draft

We built IncidentIQ for the Hindsight hackathon: an incident-response assistant that can bring a previously confirmed fix into the next investigation.

The loop: recall related incident memories → diagnose with evidence → let an engineer confirm the fix → retain it for later. Our live demo compares the same incident with and without Hindsight context, using recalled memories rather than a static mock.

Built with Hindsight, Groq, Supabase, FastAPI, and Next.js. This is a prototype; we’re still validating the full workflow and adding the access controls needed before real production use.
